## แบบบันทึกการเข้าร่วมประชุมใหญ่ (.docx)

ปุ่ม **แบบบันทึก (.docx)** (บนแถบหัวของหน้าวิเคราะห์ และบนการ์ดของแต่ละสหกรณ์ในหน้าภาพรวม) กรอกผลการวิเคราะห์ลงแบบฟอร์ม `templates/visit_template.docx` แล้วดาวน์โหลดเป็นไฟล์ Word ทันที (สร้างในเบราว์เซอร์ ไม่ส่งข้อมูลออกนอกเครื่อง) สหกรณ์ที่เพิ่มใหม่ใช้ได้เลยโดยไม่ต้องตั้งค่าเพิ่ม

เนื้อหาและรูปแบบเขียนตามตัวอย่างการวิเคราะห์ของ สอ.สาธารณสุขหนองบัวลำภู (ไฟล์ตัวอย่างที่ผู้ใช้จัดทำ ไม่ได้เก็บไว้ใน repo เพราะมีชื่อผู้แทน) ไฟล์ที่สร้างจากข้อมูลของสหกรณ์นี้ได้คะแนนรวม 17/25 และสรุป "ติดตามใกล้ชิด" ตรงกับตัวอย่าง

| ส่วนของแบบฟอร์ม | เนื้อหาที่กรอก |
|---|---|
| ชื่อสหกรณ์ | ชื่อเต็ม (ขีดเส้นใต้) ส่วนวันที่และชื่อผู้แทนเว้นไว้ให้กรอกเอง |
| Checklist (ตารางมีเส้น) | ☑ = ใช่ / ☒ = ไม่ใช่ / ต้องติดตาม พร้อมตัวเลขแบบตัวอย่าง เช่น "97.60 ลบ. (+24.2%) … ไม่นับรายการนี้ 75.21 ลบ.", current ratio เทียบปีก่อน, D/E เทียบค่าเฉลี่ย, วงเงินธนาคาร, ชื่อผู้สอบบัญชี และคดีความ ใต้ตารางมีคำอธิบายสัญลักษณ์และวันที่ของข้อมูล |
| สิ่งที่ได้เรียนรู้ | ข้อ 1–4: โครงสร้างแหล่งเงินทุน คุณภาพกำไร (แยกกำไรขายเงินลงทุนและขาดทุนที่ยังไม่เกิดขึ้น) คุณภาพสินเชื่อ และเกณฑ์ฝาก/ลงทุนไม่เกิน 10% ตามกฎกระทรวง พ.ศ. 2567 |
| แนวปฏิบัติที่ควรนำมาปรับใช้ | สิ่งที่สหกรณ์ทำได้ดีและนำมาใช้ได้ (สูงสุด 4 ข้อ) |
| ประเด็นความเสี่ยง | ความเสี่ยงที่มีตัวเลขกำกับ เช่น แหล่งเงินทุนกระจุกตัว ขาดทุนจากเงินลงทุน เงินฝากที่เกินเกณฑ์ 10% แผนกำไรปีหน้า แล้วจึงตามด้วยข้อค้นพบ (สูงสุด 6 ข้อ) |
| ข้อเสนอแนะต่อคณะกรรมการ | การจัดการวงเงิน เอกสารที่ควรขอเพิ่ม เกณฑ์ยกระดับการติดตาม การตรวจเพดาน 10% ของ สอ.บวท. และสิ่งที่ต้องติดตามจากที่ประชุมใหญ่ |
| แบบประเมิน 1–5 | คะแนนพร้อมเหตุผล และแถว "รวม" (5 = ดี/เสี่ยงต่ำ, 1 = เสี่ยงสูง) |
| สรุป | ติ๊กตามคะแนนรวม (≥22 คงวงเงิน · 18–21 ติดตามปกติ · 14–17 ติดตามใกล้ชิด · 10–13 ทบทวนวงเงิน · <10 ขอหลักประกัน) และย่อหน้า "เหตุผล" |

เกณฑ์ทั้งหมดอยู่ใน `assets/visit_form.js` (ฟังก์ชัน `assess`) ถ้าแก้ไฟล์ `templates/visit_template.docx` ให้รัน `python scripts/embed_template.py` เพื่อสร้าง `assets/visit_template.js` ใหม่ โดยคงข้อความหัวข้อและชื่อรายการในตารางไว้เหมือนเดิม เพราะโปรแกรมใช้ข้อความเหล่านั้นหาตำแหน่งที่จะกรอก

## โครงสร้าง

```
index.html            หน้าเว็บ (โหลดไฟล์ข้อมูลทุกสหกรณ์)
assets/app.js         เครื่องวิเคราะห์ (อัตราส่วน + กฎข้อค้นพบ) และหน้าจอทั้งหมด
assets/charts.js      กราฟ (ไม่พึ่งไลบรารีภายนอก)
assets/styles.css     ธีมสว่าง/มืด
data/registry.js      ทะเบียนข้อมูล
data/benchmarks.js    ค่าเฉลี่ยสหกรณ์ออมทรัพย์ทั่วประเทศ (ใช้ร่วมกันทุกสหกรณ์)
data/litigation.js    คดีความและการร้องเรียนของทุกสหกรณ์ (registerLitigation ตามรหัสสหกรณ์)
assets/visit_form.js  กรอกแบบบันทึกการเข้าร่วมประชุมใหญ่ (.docx) จากผลวิเคราะห์
assets/visit_template.js  แบบฟอร์มที่ฝังไว้ (สร้างด้วย scripts/embed_template.py)
templates/            แบบฟอร์มต้นฉบับ visit_template.docx
data/<coop>-<ปี>.js   ข้อมูลที่ถอดจากรายงานของแต่ละสหกรณ์
scripts/              เครื่องมือดึงรายงานและแปลงหน้า PDF เป็นภาพ
```

   - เว็บอื่น (เช่น supsasookamnat.com) มักมีลิงก์ไฟล์ PDF ตรงในหน้ารายงาน
2. ถ้าหน้างบการเงินเป็นภาพสแกน ให้แปลงเป็นภาพเพื่อถอดตัวเลข:
   ```bash
   python scripts/render_pages.py report.pdf out/page 26-43
   ```
3. วิธีที่เร็วที่สุด (เฉพาะงบหลัก): เขียนไฟล์ `specs/<id>-<ปี>.json` ตามตัวอย่างใน `specs/` แล้วรัน `python scripts/make_coop.py specs/<ไฟล์>.json` สคริปต์จะตรวจว่ายอดย่อยทุกกลุ่มรวมได้เท่ายอดรวมในงบ และหยุดถ้าไม่ตรง จากนั้นเขียน `data/<id>-<ปี>.js` ให้
   หรือคัดลอกไฟล์ใน `data/` เป็นไฟล์ใหม่ แก้ตัวเลขโดยคง `id` ของรายการไว้ (เช่น `total_assets`, `net_profit`, `dep_coop`, `lt_borrow`) เพราะเครื่องวิเคราะห์อ้างอิงจาก id เหล่านี้ ส่วนที่รายงานไม่มี (เช่น งบประมาณ ประมาณการปีนี้ ประวัติหลายปี) ใส่ `null` หรือละไว้ได้ หน้าจอจะข้ามส่วนนั้น
4. เพิ่มรายการใน `data/litigation.js` ด้วย `registerLitigation("<id>", {...})` หรือ `none("<id>", "<ข้อความเปิดเผยในรายงาน>")` ถ้าไม่พบคดี โดยอ่านหัวข้อการถูกร้องทุกข์ในรายงานและค้นหาชื่อเต็มของสหกรณ์คู่กับคำว่า ฟ้อง คดี ทุจริต ยักยอก ศาล ไม่ระบุชื่อบุคคลธรรมดาที่เป็นคู่ความ
5. เพิ่ม `<script src="data/<ไฟล์ใหม่>.js?v=14"></script>` ใน `index.html` แล้วสหกรณ์ใหม่จะขึ้นในหน้าภาพรวมเอง (เมื่อแก้ไฟล์ใน `assets/` หรือ `data/` ให้เพิ่มเลข `?v=` ทุกบรรทัด เพื่อไม่ให้เบราว์เซอร์ใช้ไฟล์เก่าจากแคช)

## หมายเหตุด้านข้อมูล

- ตัวเลขทุกชุดตรวจยอดรวมแล้ว: งบฐานะการเงิน งบกำไรขาดทุน งบกระแสเงินสด งบประมาณรายรายการ เงินให้กู้ เงินฝาก และเงินลงทุน ตรงกับยอดรวมในงบทั้งหมด
- ตัวเลขในรายงานที่ไม่สอดคล้องกัน แสดงไว้ในแท็บข้อค้นพบ หัวข้อ "ความถูกต้องของรายงาน" (หนองบัวลำภู 3 จุด, อำนาจเจริญ 5 จุด)
- ค่าเฉลี่ยเปรียบเทียบเป็นค่าที่รายงานของ สอ.สาธารณสุขหนองบัวลำภู อ้างจากศูนย์ข้อมูลทางการเงิน กรมตรวจบัญชีสหกรณ์ (ปี 2568) และใช้กับทุกสหกรณ์ออมทรัพย์
- ROA/ROE ที่คำนวณเองใช้ยอดถัวเฉลี่ยต้นปีและสิ้นปี (วิธีเดียวกับค่าเฉลี่ย) ค่าปีก่อนที่มีเครื่องหมาย ≈ ใช้ยอดสิ้นปีเพราะรายงานไม่มียอดต้นปีของปีก่อน
- ไม่ได้นำรายชื่อบุคคลจากรายงาน (เช่น รายชื่อสมาชิกที่เสียชีวิต ค่าตอบแทนกรรมการรายบุคคล) มาแสดง
