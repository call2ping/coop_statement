# วิเคราะห์รายงานประจำปีสหกรณ์

เว็บสำหรับวิเคราะห์รายงานประจำปีล่าสุดของสหกรณ์ออมทรัพย์ ที่เผยแพร่บนเว็บไซต์ของสหกรณ์

| สหกรณ์ | รายงาน | ที่มา |
|---|---|---|
| สหกรณ์ออมทรัพย์สาธารณสุขจังหวัดหนองบัวลำภู จำกัด | ผลการดำเนินงานประจำปี 2569 (ปีบัญชีสิ้นสุด 30 ก.ย. 2569) | [hnbpcoop.com](https://www.hnbpcoop.com/index.php?module=outcame2&cat=2) |
| สหกรณ์ออมทรัพย์สาธารณสุขจังหวัดอำนาจเจริญ จำกัด | รายงานกิจการประจำปี 2569 (ปีบัญชีสิ้นสุด 30 ก.ย. 2569) | [supsasookamnat.com](https://www.supsasookamnat.com/reports.php) |
| สหกรณ์ออมทรัพย์สาธารณสุขจังหวัดอุดรธานี จำกัด | รายงานประจำปี 2569 (เฉพาะงบหลัก) | [udcoop.com](https://www.udcoop.com/download/index.php?catid=16) |
| สหกรณ์ออมทรัพย์สาธารณสุขนครราชสีมา จำกัด | รายงานประจำปี 2568 (ฉบับ 2569 ยังไม่เผยแพร่; เฉพาะงบหลัก) | [koratcoop.com](https://www.koratcoop.com/web2020/ebook/report/report_year68/) |
| สหกรณ์ออมทรัพย์สาธารณสุขสงขลา จำกัด | รายงานกิจการ 2568 (เฉพาะงบหลัก) | [spsccoop.com](http://spsccoop.com/) |
| สหกรณ์ออมทรัพย์สาธารณสุขจังหวัดพังงา จำกัด | รายงานกิจการ 2568 (เฉพาะงบหลัก) | [phangngacoop.com](https://www.phangngacoop.com/) |
| สหกรณ์ออมทรัพย์สาธารณสุขกาญจนบุรี จำกัด | รายงานกิจการ 2568 (ปีบัญชีสิ้นสุด 31 ต.ค.; เฉพาะงบหลัก) | [kancoop-ph.com](http://kancoop-ph.com/images/pdf/anual2568.pdf) |

แต่ละแห่งใช้รายงานฉบับล่าสุดที่เผยแพร่บนเว็บของสหกรณ์ ณ วันที่ดึงข้อมูล ปีบัญชีจึงต่างกันได้ (หน้าภาพรวมมีตัวกรองปีบัญชี)

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือรันเซิร์ฟเวอร์ภายในเครื่อง:

```bash
python -m http.server 8765
```

แล้วเข้า http://127.0.0.1:8765

## หน้าที่มี (ทุกหน้ามีตัวกรอง)

เว็บเปิดที่ **หน้าภาพรวมทุกสหกรณ์** (`#/`) แล้วกดเลือกสหกรณ์เพื่อเข้าหน้าวิเคราะห์ (`#/<รหัสสหกรณ์>/<แท็บ>` เช่น `#/acrcoop/findings`) ปุ่มย้อนกลับของเบราว์เซอร์และปุ่ม "← ภาพรวมทุกสหกรณ์" พากลับหน้าแรก

**หน้าภาพรวมทุกสหกรณ์**

| ส่วน | เนื้อหา | ตัวกรอง |
|---|---|---|
| ตัวเลขรวม | จำนวนสหกรณ์ สินทรัพย์ เงินให้กู้ กำไร สมาชิก และจำนวนประเด็นความเสี่ยง/เฝ้าระวัง รวมทุกแห่ง | ค้นหาชื่อ/จังหวัด, เรียงลำดับ, เฉพาะสหกรณ์ที่มีประเด็นความเสี่ยง (ใช้กับทุกส่วนของหน้า) |
| เลือกสหกรณ์ | การ์ดของแต่ละแห่ง: กำไร ตัวเลขหลัก จำนวนข้อค้นพบแต่ละระดับ ประเด็นสำคัญที่สุด และปุ่มเข้าหน้าวิเคราะห์ | |
| อัตราส่วนเทียบค่าเฉลี่ย | กราฟ Current ratio, D/E, ROA, ROE, NPM ของทุกแห่งเทียบค่าเฉลี่ยสหกรณ์ออมทรัพย์ | |
| ประเด็นจากการวิเคราะห์ | ตารางหัวข้อ × สหกรณ์ แสดงระดับที่รุนแรงที่สุด กดช่องเพื่อเปิดข้อค้นพบของหัวข้อนั้น | เฉพาะหัวข้อที่มีความเสี่ยงหรือเฝ้าระวัง |
| เปรียบเทียบตัวเลขและอัตราส่วน | ตารางเทียบทุกแห่ง พร้อมป้าย "อันดับ 1" | หมวดอัตราส่วน, เฉพาะที่มีค่าเฉลี่ย |

| แท็บ | เนื้อหา | ตัวกรอง |

| สินเชื่อ เงินฝาก และแหล่งเงินทุน | เงินให้กู้ตามประเภท, เงินรับฝากและเงินกู้ยืม, เงินฝากสหกรณ์อื่น, เงินลงทุน, แหล่งเงินกู้และวงเงิน | ส่วนที่แสดง, ค้นหา, เฉพาะรายการที่เป็นความเสี่ยง |

## โครงสร้าง

```
index.html            หน้าเว็บ (โหลดไฟล์ข้อมูลทุกสหกรณ์)
assets/app.js         เครื่องวิเคราะห์ (อัตราส่วน + กฎข้อค้นพบ) และหน้าจอทั้งหมด
assets/charts.js      กราฟ (ไม่พึ่งไลบรารีภายนอก)
assets/styles.css     ธีมสว่าง/มืด
data/registry.js      ทะเบียนข้อมูล
data/benchmarks.js    ค่าเฉลี่ยสหกรณ์ออมทรัพย์ทั่วประเทศ (ใช้ร่วมกันทุกสหกรณ์)
data/<coop>-<ปี>.js   ข้อมูลที่ถอดจากรายงานของแต่ละสหกรณ์
scripts/              เครื่องมือดึงรายงานและแปลงหน้า PDF เป็นภาพ
```

## เพิ่มสหกรณ์ใหม่

1. หาหน้ารายงานประจำปีบนเว็บไซต์สหกรณ์แล้วดาวน์โหลด PDF
   - เว็บที่ใช้โมดูลดาวน์โหลดแบบ GCMS (เช่น hnbpcoop.com) ใช้สคริปต์นี้ได้:
     ```bash
     python scripts/fetch_reports.py list "https://<เว็บสหกรณ์>/index.php?module=outcame2&cat=2"
     ```
   - เว็บอื่น (เช่น supsasookamnat.com) มักมีลิงก์ไฟล์ PDF ตรงในหน้ารายงาน
2. ถ้าหน้างบการเงินเป็นภาพสแกน ให้แปลงเป็นภาพเพื่อถอดตัวเลข:
   ```bash
   python scripts/render_pages.py report.pdf out/page 26-43
   ```
3. วิธีที่เร็วที่สุด (เฉพาะงบหลัก): เขียนไฟล์ `specs/<id>-<ปี>.json` ตามตัวอย่างใน `specs/` แล้วรัน `python scripts/make_coop.py specs/<ไฟล์>.json` สคริปต์จะตรวจว่ายอดย่อยทุกกลุ่มรวมได้เท่ายอดรวมในงบ และหยุดถ้าไม่ตรง จากนั้นเขียน `data/<id>-<ปี>.js` ให้
   หรือคัดลอกไฟล์ใน `data/` เป็นไฟล์ใหม่ แก้ตัวเลขโดยคง `id` ของรายการไว้ (เช่น `total_assets`, `net_profit`, `dep_coop`, `lt_borrow`) เพราะเครื่องวิเคราะห์อ้างอิงจาก id เหล่านี้ ส่วนที่รายงานไม่มี (เช่น งบประมาณ ประมาณการปีนี้ ประวัติหลายปี) ใส่ `null` หรือละไว้ได้ หน้าจอจะข้ามส่วนนั้น
4. เพิ่ม `<script src="data/<ไฟล์ใหม่>.js?v=7"></script>` ใน `index.html` แล้วสหกรณ์ใหม่จะขึ้นในหน้าภาพรวมเอง (เมื่อแก้ไฟล์ใน `assets/` หรือ `data/` ให้เพิ่มเลข `?v=` ทุกบรรทัด เพื่อไม่ให้เบราว์เซอร์ใช้ไฟล์เก่าจากแคช)

## หมายเหตุด้านข้อมูล

- ตัวเลขทุกชุดตรวจยอดรวมแล้ว: งบฐานะการเงิน งบกำไรขาดทุน งบกระแสเงินสด งบประมาณรายรายการ เงินให้กู้ เงินฝาก และเงินลงทุน ตรงกับยอดรวมในงบทั้งหมด
- ตัวเลขในรายงานที่ไม่สอดคล้องกัน แสดงไว้ในแท็บข้อค้นพบ หัวข้อ "ความถูกต้องของรายงาน" (หนองบัวลำภู 3 จุด, อำนาจเจริญ 5 จุด)
- ค่าเฉลี่ยเปรียบเทียบเป็นค่าที่รายงานของ สอ.สาธารณสุขหนองบัวลำภู อ้างจากศูนย์ข้อมูลทางการเงิน กรมตรวจบัญชีสหกรณ์ (ปี 2568) และใช้กับทุกสหกรณ์ออมทรัพย์
- ROA/ROE ที่คำนวณเองใช้ยอดถัวเฉลี่ยต้นปีและสิ้นปี (วิธีเดียวกับค่าเฉลี่ย) ค่าปีก่อนที่มีเครื่องหมาย ≈ ใช้ยอดสิ้นปีเพราะรายงานไม่มียอดต้นปีของปีก่อน
- ไม่ได้นำรายชื่อบุคคลจากรายงาน (เช่น รายชื่อสมาชิกที่เสียชีวิต ค่าตอบแทนกรรมการรายบุคคล) มาแสดง
